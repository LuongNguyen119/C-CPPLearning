## Mục tiêu
Mở rộng khóa C++ từ 31 lên khoảng 90 bài, tương đương khóa C, bao phủ C++ hiện đại từ nền tảng đến STL, OOP, template, memory safety và C++20.

## Hiện trạng
- `CPP/cpp_lessons.js` có factory `E(...)`, 31 lesson, 11 chapter.
- `CPP/cpp_exercises.js` có 35 exercise, 7 topic, mỗi topic 5 bài.
- `CPP/cpp_app.js` đã có renderer lesson/exercise, hash route, sidebar, search, quiz, progress, dark mode và gọi backend `/api/run`.
- `CPP/cpp_content_check.js` đã kiểm tra schema cơ bản.
- Không đổi `C.html` hoặc các file C.

## Cách triển khai
1. Giữ factory lesson và schema hiện tại để không phá renderer.
2. Thêm một block `moreLessons` vào cuối `cpp_lessons.js`, dùng factory hiện có, mỗi bài có:
   - id/slug duy nhất;
   - chapter;
   - prerequisite tới bài trước hoặc bài nền tảng phù hợp;
   - concept riêng, không placeholder;
   - syntax;
   - ví dụ C++ compile-ready với include đúng;
   - output và explanation;
   - use cases, notes, common mistake, key takeaways;
   - 3 quiz riêng.
3. Bổ sung khoảng 59 bài để đạt 90 lesson, chia các nhóm:
   - C++ nền tảng: namespace, `std::endl`, stream state, `getline`, enum, references, pointer an toàn.
   - Containers: `array`, `deque`, `list`, `stack`, `queue`, `priority_queue`, `unordered_map`, `unordered_set`, `tuple`, `optional`, `variant`, `string_view`, `span`.
   - Algorithms: `count`, `find`, `max_element`, `accumulate`, `transform`, `remove_if`, `partition`, binary search, comparator, iterator invalidation, ranges/views.
   - OOP: operator overloading, abstract class, interface, virtual dispatch, copy constructor, copy assignment, move constructor, move assignment, Rule of 0/3/5, object slicing, composition.
   - Templates: function template, class template, template parameters, specialization, variadic/fold expression, `if constexpr`, type traits, concepts/constraints.
   - Memory safety: lifetime, dangling pointer, ownership/borrowing, exception safety, `weak_ptr`/cycle, custom RAII, bounds checking, undefined behavior, sanitizers.
   - Modern C++: structured bindings, `decltype`, `std::move`, `constexpr`, `consteval`, `filesystem`, `chrono`, `regex`, three-way comparison, `expected`/C++23 note, concurrency overview.
   - Projects/reference: testing strategy, project structure, standard library reference.
4. Sửa `E(...)` để nhận `exerciseIds` tùy chọn hoặc sau khi tạo lesson gán exercise theo topic; tránh mọi lesson trỏ cùng `cpp-ex-001`.
5. Mở rộng `cpp_exercises.js` lên tối thiểu 50 bài, thêm 5 bài cho các topic mới như OOP, Templates, Memory Safety, Modern C++ và Files/STL.
6. Cập nhật `cpp_content_check.js` để kiểm tra:
   - 80–100 lesson;
   - unique lesson/exercise id và slug;
   - required fields và concept length;
   - compile-ready marker/include cho examples;
   - prerequisite tồn tại;
   - quiz answer range;
   - exercise topic có ít nhất 5 bài;
   - không placeholder.
7. Cập nhật home/tiến độ nếu số bài đang ghi tĩnh; app chính phải lấy động từ `lessons.length`.
8. Không thêm compiler command từ client; giữ backend `g++ -std=c++20 -Wall -Wextra -pedantic`, ghi rõ local trusted runner.

## Kiểm thử
- `node --check CPP/cpp_lessons.js CPP/cpp_exercises.js CPP/cpp_app.js CPP/cpp_content_check.js`.
- `python -m py_compile CPP/cpp_server.py`.
- `node CPP/cpp_content_check.js`.
- Smoke-test `GET /CPP.html` và POST `/api/run` với `std::cout`.
- Kiểm tra hash route, sidebar/search, previous/next, quiz, progress, exercises, dark mode, responsive.
